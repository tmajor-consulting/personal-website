# Redesign Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Redesign the personal website to clearly position Tamas as a senior Engineering Manager, add a consulting section, modernise the skills display, and ship a clean, production-grade codebase with tests.

**Architecture:** Single long-scroll page. Content flows from `data/data.tsx` (source of truth) into presentational section components. No new pages — sections compose in `pages/index.tsx`. Tests co-located with components.

**Tech Stack:** Next.js 15 (Pages Router), React 19, TypeScript strict, Tailwind CSS 4 (CSS-native config), Jest + @testing-library/react, Yarn 4 (use `npm run` scripts).
